# FocusLoop

A cross-platform task timing and Ebbinghaus review app for Android / iOS / Windows / macOS.

## Features

- Task timing with target duration, pause/resume support
- Ebbinghaus review tasks that resurface automatically along the forgetting curve
- Task categories
- Multi-device data sync (Local-first + Supabase, in progress)

## Getting started

```bash
flutter pub get
flutter run -d windows    # or macos / an Android device / an iOS simulator
flutter test              # run unit tests
flutter analyze           # static analysis
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for the full architecture design.
